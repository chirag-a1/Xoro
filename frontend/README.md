# Xoro Premium Trading App (Frontend)

This folder contains the React frontend for the Xoro Premium Trading App.

## Features
- Modern UI for trading and portfolio management
- Live market data and charts
- AI-powered trading recommendations
- Order ticket and trade history
- Watchlists and stock screener

## Setup
1. Install dependencies:
	```bash
	npm install
	```
2. Start the frontend server:
	```bash
	npm start
	```
	The app runs at `http://localhost:3000`.

## Usage
- Connects to the Flask backend at `http://localhost:5000`
- Use the dashboard to view portfolio, place trades, and get AI recommendations
